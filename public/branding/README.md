# DEBWAN LIVE — Brand Assets

ارفع الصور الأصلية الخاصة بهوية دبوان لايف إلى هذا المجلد من زر **Add file → Upload files** أو من صفحة الرفع المباشرة:

https://github.com/mghalaosimi-web/debwan-live/upload/main/public/branding

## الملفات المطلوبة

1. `debwan-icon.png` — صورة الرجل الأصلية المستخدمة كأيقونة التطبيق. يفضّل PNG مربعة بدقة 1024×1024.
2. `debwan-hero.png` — الصورة/التصميم العريض الذي سيظهر في الواجهة الرئيسية. يفضّل PNG أو WebP بنسبة 16:9 وبعرض 1920px على الأقل.

## تعليمات الهوية

- استخدم صورة الرجل الأصلية كما هي مرجعاً للوجه.
- لا تغيّر ملامح الوجه أو تستبدله بوجه مولّد.
- يمكن تحسين الإضاءة والحدة والتدرج اللوني والخلفية فقط.
- اجعل التدرج اللوني فاخراً ومتناسقاً مع هوية DEBWAN LIVE، مع خلفية رياضية أنيقة وغير مزدحمة.
- لا تضع نصوصاً داخل الصورة إلا إذا كانت مطلوبة صراحةً.

بعد رفع الملفين، أرسل رابط هذه الصفحة في المحادثة أو أخبرني أن الرفع اكتمل حتى أراجع الصور وأحدد طريقة دمجها في التطبيق.
